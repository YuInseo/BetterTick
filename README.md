## 내 근무에 맞춰, 일상을 정리해요

요일마다 같은 생활을 반복하기 어려운 교대 근무자에게는 근무표가 계획의 기준이 됩니다. BetterTick은 그 근무표 위에 할 일과 생활 루틴을 함께 놓을 수 있도록 만들었습니다.

주간 근무일에는 퇴근 후 운동을, 야간 근무일에는 출근 전 수면을 연결해 보세요. 남은 휴가와 이번 달 수입·지출도 같은 앱에서 확인할 수 있습니다.

## 주요 기능

### 🗓️ 근무표와 달력

- **주간 · 야간 · 비번 · 휴무 · 당직 · 일근**을 색상으로 구분하고, 날짜별로 근무를 변경할 수 있습니다.
- 입력한 근무에서 반복 패턴을 찾아 이후 일정을 채웁니다.
- **월 · 주 · 일 · 목록 · 연도 보기**로 일정을 살펴보고, 드래그로 날짜를 옮기거나 타임라인에 새 일정을 만듭니다.
- 한국 공휴일과 대체공휴일을 표시하며, 필요하면 직접 수정할 수 있습니다.

### ✅ 근무와 함께 반복되는 할 일

- 목록, 태그, 우선순위, 고정, 알림으로 할 일을 정리합니다.
- 매일·매주·매달·매년 반복과 직접 설정한 주기, **근무 패턴에 맞춘 반복**을 지원합니다.
- 할 일을 다른 할 일 아래로 끌어 놓아 하위 할 일로 연결합니다. 수면이나 운동을 근무 아래에 두면 근무 일정에 맞춰 함께 반복됩니다.
- 반복 할 일은 날짜별로 완료할 수 있고, 한 번의 체크로 전체 반복을 완료하도록 설정할 수도 있습니다.
- 메모는 해당 날짜에만 남기거나 모든 반복에 표시할 수 있습니다.
- 내일로 미루기, 삭제 실행 취소, CSV 가져오기·내보내기를 지원합니다.

### 🌿 남은 휴가를 한눈에

- 지휴 · 특휴 · 연차 · 병가의 부여 일수와 초기화 기준을 설정합니다.
- 매월, 매년, 입사일 기준, 초기화 없음 중에서 선택하고, 근속 연차에 따라 부여 일수를 다르게 정할 수 있습니다.
- 공휴일 근무에 따른 **지휴 자동 적립**을 지원합니다. 포함할 요일과 근무별 적립 일수를 조정하거나, 기간별 총일수를 직접 입력할 수도 있습니다.
- 근무지별 재직 기간과 휴가 규칙을 관리하고, 사용 내역과 잔여 일수를 확인합니다.

### 💰 월급과 가계부

- 회사별 월급일과 지급·공제 항목을 설정하고, 월별·분기별·연간 수입을 확인합니다.
- 매월 반복, 분기별, 매년 지정한 달, 일회성 항목을 등록하고 실제 수령액을 월별로 수정할 수 있습니다.
- 추가 수입과 지출을 기록해 **이번 달 수입과 지출, 남은 금액**을 함께 살펴봅니다.
- 필요할 때 군 복무 급여 계산을 켤 수 있습니다. 입대일과 복무 유형을 기준으로 계산하며, 계급별 기간과 금액도 직접 조정할 수 있습니다.

### 🎯 하루를 채우는 도구

| 도구 | 할 수 있는 일 |
| --- | --- |
| 습관 | 매일의 실천을 체크하고 기록과 통계 확인 |
| 뽀모도로 | 집중 타이머·스톱워치와 집중 기록 |
| 일기 | 날짜별로 하루의 기록 남기기 |
| 동선 | 이동 기록을 카카오맵에서 확인 |
| 아이젠하워 매트릭스 | 중요도와 긴급도에 따라 할 일 정리 |

### 📱 앱 밖에서도 빠르게

- 홈 화면 위젯에서 일정과 할 일을 확인하고, 빠르게 추가할 수 있습니다.
- 할 일·습관 알림과 하루 요약을 받고, 알림에서 바로 완료하거나 10분 뒤로 미룰 수 있습니다.
- 잠금화면 입력과 다른 앱 위에 표시되는 빠른 추가를 지원합니다.
- 테마와 강조색, 시간 표시, 주 시작 요일, 하단 탭의 순서와 구성을 내 방식에 맞게 바꿀 수 있습니다.

## 시작하기

1. **[최신 APK](https://github.com/YuInseo/BetterTick/releases/download/latest-debug/BetterTick.apk)**를 내려받아 설치합니다.
2. 근무 일정과 반복 패턴을 등록합니다.
3. 설정에서 근무지와 휴가 규칙을 맞춘 뒤, 할 일과 생활 루틴을 추가합니다.
4. 자주 쓰는 기능으로 하단 탭을 구성하고 위젯을 배치합니다.

> **설치 안내**  
> 현재 제공되는 APK는 개발용 Debug 빌드이며, Android 9 이상인 ARM64 기기를 대상으로 합니다. APK 다운로드에는 GitHub 로그인이 필요하지 않습니다.  
> 앱에서 새 버전을 확인하고 업데이트를 진행할 수 있으며, 기기 환경에 따라 Android의 설치 허용이나 확인이 필요할 수 있습니다.

## 데이터 저장과 동기화

화면은 기기에 저장된 Firestore 캐시를 먼저 읽습니다. 이미 불러온 데이터는 오프라인에서도 확인하고 수정할 수 있으며, 연결이 복구되면 변경 내용이 서버에 반영됩니다.

| 데이터 | 저장 방식 |
| --- | --- |
| 할 일 등 Firestore에서 관리하는 데이터 | 기기 캐시와 Firebase 서버에 저장 |
| 회사·휴가 규칙, 월급·가계부, 화면 설정 | 기기의 SharedPreferences에 저장 |

다른 기기에서 변경한 할 일은 백그라운드 작업으로 주기적으로 가져옵니다. 작업은 약 15분 간격으로 예약되며, 실제 실행 시점은 Android의 백그라운드 정책에 따라 달라질 수 있습니다.

**기기에만 저장되는 설정과 가계부 데이터는 기기 간 동기화 대상이 아닙니다.** Firestore 데이터 구조는 [FIRESTORE_SCHEMA.md](FIRESTORE_SCHEMA.md)에서 확인할 수 있습니다.

## 개발하기

### 기술 스택

| 영역 | 기술 |
| --- | --- |
| 언어 · UI | Kotlin 2.0 · Jetpack Compose · Material 3 |
| 앱 구조 | MVVM · Hilt · Coroutines / Flow |
| 인증 · 데이터 | Firebase Authentication · Cloud Firestore · SharedPreferences |
| 위젯 · 백그라운드 | Glance · WorkManager · AlarmManager |
| 지도 | Kakao Map SDK · 카카오모빌리티 길찾기 API |
| 빌드 | Gradle · AGP 8.5 · KSP · Version Catalog |

### 로컬 실행

**준비:** Android Studio, JDK 17, Android SDK 34

```bash
git clone https://github.com/YuInseo/BetterTick.git
cd BetterTick

# Debug APK 빌드
./gradlew assembleDebug

# 단위 테스트 및 Lint 검사
./gradlew testDebugUnitTest lintDebug
```

빌드된 APK는 `app/build/outputs/apk/debug/app-debug.apk`에 생성됩니다. Android Studio에서 프로젝트를 열고 `app`을 실행해도 됩니다. Windows에서는 `./gradlew` 대신 `gradlew.bat`을 사용합니다.

<details>
<summary><strong>추가 설정과 빌드 옵션</strong></summary>

- **카카오 길찾기:** `local.properties`에 `KAKAO_REST_API_KEY`를 설정합니다. 키가 없으면 길찾기 경로 대신 직선으로 표시하는 대체 동작을 사용합니다. [설정 예시](local.properties.example)를 참고하세요.
- **별도 Firebase 프로젝트:** 저장소의 `app/google-services.json`은 기존 프로젝트용입니다. 자체 환경에서 운영하려면 해당 파일을 교체하고, 인증·Firestore 설정과 Google 로그인 클라이언트 ID 및 서명 지문도 맞춰야 합니다.
- **축소 테스트 빌드:** `./gradlew assembleSmall`로 R8 최적화를 적용한 APK를 만듭니다. Debug와 같은 패키지·서명을 사용합니다.
- **Release 서명:** [keystore.properties.example](keystore.properties.example)과 [RELEASE.md](RELEASE.md)를 참고하세요.

</details>

### 프로젝트 구조

```text
app/src/main/java/com/bettertick/
├── data/          # 데이터 모델, Firebase 연동, 저장소
├── ui/
│   ├── navigation/  # 화면 이동과 공통 내비게이션
│   ├── screens/     # 할 일, 달력, 가계부, 설정 등
│   └── theme/       # 테마, 색상, 앱 설정
├── widget/        # 홈 화면 위젯과 갱신 작업
├── reminder/      # 알림 예약과 처리
├── update/        # 업데이트 확인, 다운로드, 설치
├── overlay/       # 화면 위 빠른 추가
└── location/      # 위치 기록
```

단위 테스트는 `app/src/test/`에 있으며, 하위 할 일, 반복 완료, 휴가, 급여, 가계부 등의 계산 로직을 검증합니다.

### 검증과 배포

- **PR 검증:** GitHub Actions에서 Debug 빌드, Lint, 단위 테스트를 실행합니다.
- **APK 배포:** `main`의 앱 변경 사항은 빌드 후 [latest-debug 릴리즈](https://github.com/YuInseo/BetterTick/releases/tag/latest-debug)에 게시됩니다. Markdown 문서만 변경하면 APK 배포는 실행되지 않습니다.
- **앱 업데이트:** 릴리즈의 버전 정보를 확인해 새 APK를 내려받고 설치를 진행합니다.
